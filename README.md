# Agenda de Consultas e Exames

Sistema web para agendar consultas e exames hospitalares, feito com HTML, CSS e JavaScript.

## Funcionalidades

- Cadastro de agendamentos (paciente, data, tipo e médico)
- Listagem dos agendamentos na tela
- Busca/filtro em tempo real por nome, tipo ou médico
- Cancelamento de agendamentos
- Validação de datas (não permite agendar no passado)
- Dados salvos no navegador com localStorage

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone o repositório: `git clone https://github.com/Marcelohnrk/agenda-facil.git`
2. Abra o arquivo `index.html` no navegador
